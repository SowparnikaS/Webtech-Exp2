# Webtech-Exp2

Aim :
To design and develop an HTML5 webpage using various HTML elements such as headings, paragraphs, images, hyperlinks, tables, forms, audio, video and embedded webpages.

Description:
HTML5 is a markup language used to create and structure webpages. It provides different tags to display text, images, tables, multimedia content and forms. In this experiment, an HTML5 webpage named My HTML5 Showcase Page is created using various HTML elements. It also includes a student registration form with different input fields such as name, email, date of birth, gender, hobbies, skill level and course selection.

Procedure:
1.	Open Visual Studio Code.
2.	Create a new folder for the HTML5 experiment.
3.	Create a new file named exp2.html.

4.	Open the file and write the basic HTML5 structure using <!DOCTYPE html>, <html>, <head> and <body> tags.

5.	Add a title and heading using the <title> and <h1> tags.

6.	Add an introductory paragraph using the <p> tag.

7.	Insert an image using the <img> tag. 
8.	Add a hyperlink using the <a> tag to visit W3Schools.
9.	Create a table using the <table>, <tr>, <th> and <td> tags.
10.	Create a student registration form using the <form> and <fieldset> tags.
11.	Add different input fields such as text, email, date, telephone and password.
12.	Include radio buttons for gender and checkboxes for hobbies.
13.	Add a range slider, file upload option, course selection dropdown and progress bar.
14.	Insert audio and video using the HTML5 <audio> and <video> tags.
15.	Add a media file hyperlink and embed an external webpage using the <iframe> tag.
16.	Save the file and open it in a web browser to view the output.
